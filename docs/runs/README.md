# Run reports

One file per run day: `YYYY-MM-DD.md`. Written by the orchestrator, top-loaded so the owner can
read it in 60 seconds at their desk.

Order, always:

1. **Landed** — PRs awaiting your apply, with reversibility class
2. **Needs your decision** — the exact question, options, recommendation
3. **Unknown / unproven** — what could not be established, and why
4. **Next ready issues**
5. **Run stats** — issues attempted, attempts per issue, review verdicts, wall time

No optimism, no padding. Two parked issues with sharp questions beat six built on assumptions.
